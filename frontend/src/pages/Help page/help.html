Popular Topics

Create a room to invite nearby devices, or join an existing room using its room code and PIN. You can also scan a QR code to join quickly.

Select a file and choose Upload & Send. Files are uploaded to the room's LocalLink backend and listed for room participants. Both devices must be able to reach that backend, usually over the same Wi-Fi or hotspot.

Room sessions are authenticated and access is limited to room participants. Chat and files are processed by the LocalLink backend; this version does not provide end-to-end encryption. Avoid sharing sensitive information, and use HTTPS when the network is not trusted.

If a device cannot connect, check that both devices are on a compatible local network, verify the room code and PIN, and check whether firewall settings are blocking the connection. Make sure your browser supports the required features.

Does LocalLink require internet?

Communication over a compatible local network can work without internet. Remote relay transfers require internet access.

Can I share large files?

Local transfers support file sharing over supported connections. Internet-relay transfers have a 30 MB limit.

Do I need to install an application?

LocalLink is designed to work through a compatible web browser.
